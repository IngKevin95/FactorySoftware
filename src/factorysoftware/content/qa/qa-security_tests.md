# security_tests

Realiza una pasada holística sobre todo el sistema integrado: aplica SAST, escaneo de dependencias, y valida escenarios puntuales de seguridad que las auditorías de Construcción por épica no pudieron ver (por ej., la combinación de un endpoint de una épica con datos de otra).
Aplica sobre el código integrado para generar hallazgos de seguridad.
